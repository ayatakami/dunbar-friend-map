# ダンバー友達マップ

ダンバー数(5 / 15 / 50 / 150人の層)をもとに、人間関係を同心円で可視化するアプリです。

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけで使えます。インストールは不要です。

1. 右側のフォームから友達を追加します。
2. 名前のアイコンを円の中へドラッグして、層を決めます。内側ほど親しい人です。一番外の円より外に落とすと未配置に戻ります。
3. アイコンをクリックすると、タグ、最終連絡日、メモを編集できます。層はここからも変更できます。

## 層

人数は累計で判定します。「親しい仲間 15人」には内側の「親友」も含まれます。

| 層 | 累計の上限 | 連絡の目安 |
|---|---|---|
| 親友 | 5人 | 7日以内 |
| 親しい仲間 | 15人 | 30日以内 |
| 友人 | 50人 | 180日以内 |
| 友達・知人 | 150人 | 365日以内 |

上限を超えても配置はでき、警告が出ます。最終連絡日から目安の日数を超えた人は、疎遠になりかけている人として表示されます。最終連絡日が未記録の人は対象外です。

連絡の目安の日数はアプリ側で決めた既定値です。変更するには `js/logic.js` の `LAYERS` を編集します。

## データの保存先

**データはこのPCのブラウザの中(`localStorage`)にだけ保存されます。** 外部への通信は行いません。

- ブラウザの閲覧データを消去すると、データも消えます。
- 別のブラウザや別のPCからは見えません。
- このフォルダを OneDrive で同期していても、データは同期されません。
- フォルダを移動すると、ブラウザによってはデータが見えなくなることがあります。

バックアップするには、次のCSVの書き出しを使ってください。

## CSVでの書き出しと読み込み

サイドバーの「CSVに書き出す」で全員分を保存でき、「CSVを読み込む」で取り込めます。Excelで編集して保存し直したファイルも読み込めます(UTF-8、Shift_JIS のどちらにも対応)。

| 列 | 書き方 |
|---|---|
| 名前 | 必須 |
| 層 | 親友 / 親しい仲間 / 友人 / 友達・知人 / 未配置(空欄も未配置) |
| タグ | `大学、趣味` のように区切る |
| 最終連絡日 | `2026-11-05`(`2026/11/5` や `2026年11月5日` でも可) |
| メモ | 自由に記入 |

必須なのは「名前」の列だけです。列の順番は問わず、知らない列は無視します。

読み込むときは、取り込む前に確認画面で取り込み方を選びます。

- **追加・更新:** 名前が同じ人を更新し、いなければ追加します。CSVにない人は残ります。同姓同名は上から順に対応させます。
- **すべて置き換える:** 今のデータを消して、CSVの内容だけにします。元に戻せません。

追加・更新では、列はあるのにセルが空だと、その値を消します。列そのものがなければ、今の値を残します。層や日付が読めない行は取り込まず、確認画面に行番号を表示します。

名前やメモが `=` `+` `-` `@` で始まるときは、Excelが数式と解釈しないよう、先頭に `'` を付けて書き出します。読み込むときに取り除くので、データは変わりません。

## 開発

依存パッケージはなく、ビルドも不要です。

```bash
node --test
```

ローカルサーバーで動かす場合は次のとおりです。`file://` とはデータの保存先が別になります。

```bash
python -m http.server 4173
```

| ファイル | 役割 |
|---|---|
| `js/logic.js` | 層の定義、人数の集計、疎遠判定、配置計算(DOM非依存) |
| `js/csv.js` | CSVの変換と取り込み処理(DOM非依存) |
| `js/store.js` | `localStorage` の読み書きと検証 |
| `js/map.js` | 同心円の描画とドラッグ |
| `js/ui.js` | サイドバーとフォーム |
| `js/csv-panel.js` | CSVのボタンと読み込みの確認ダイアログ |
| `js/app.js` | 状態管理と初期化 |
